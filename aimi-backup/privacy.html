AIMi Backup privacy notice

Last updated: 26 October 2026

Who operates the app

Darren Peake operates AIMi Backup for his own home server and Google account. It is a personal backup utility, not a service accepting other people's accounts. Contact: darrenpeake@gmail.com.

Google data accessed

The app requests Google Drive's drive.file permission. It creates and reads its encrypted backup files and their metadata, and checks the authorised account's email address and storage quota. Access is limited to files created by, or explicitly made available to, the app. It does not request Gmail, Google Photos or general access to unrelated Drive files.

Purpose and storage

Access is used only to upload, verify and recover the operator's backups and check that the correct account has sufficient space. Restic encrypts backup contents and metadata on the home server before sending them to Google Drive.

Google authorisation tokens and the backup encryption password are stored in access-restricted files on the operator's server. Consistent database copies are prepared locally. Restore tests use separate local storage; successful test copies are removed after verification. Encrypted recovery material may include credentials needed to rebuild the server.

Sharing and use limits

Encrypted backups are stored with Google Drive. The app does not publish backup contents, sell Google user data, share it with advertisers or use it to train AI models. Google data is used only for the personal backup and recovery functions described here.

AIMi Backup's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and revoking access

Backup snapshots are retained until the operator approves a retention or deletion action. Storage and snapshot limits stop new uploads rather than silently deleting recovery points. Google authorisation can be revoked through the Google Account connections page.

Revoking access stops future authorised access; it does not automatically remove existing backups or local recovery copies. The operator can separately delete those copies when no longer required.

This information page

This page is hosted on GitHub Pages. The host may process technical request information, such as IP addresses, to deliver and secure the website. These AIMi Backup pages contain no forms, advertising or analytics scripts. The wider website has its own website privacy notice.

Changes and enquiries

This notice will be updated if the app's data practices change. Send questions about the app or its data to darrenpeake@gmail.com.
