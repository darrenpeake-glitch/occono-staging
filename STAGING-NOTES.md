# Occono

This site is live as Occono — Practical AI Systems for small businesses and solopreneurs. It is a public content site, not a noindex studio staging site.

## Hosting

- GitHub Pages serves this repository (`darrenpeake-glitch/occono-staging`) from the default branch `main`.
- The custom domain is `www.occono.co.uk`, set in `CNAME`.
- Canonical URLs use `https://www.occono.co.uk/`.
- `robots.txt` allows crawlers and points to `https://www.occono.co.uk/sitemap.xml`.

## What is published

- Homepage: `index.html`
- Articles under `posts/`
- Legal pages: `privacy.html`, `cookies.html`, `accessibility.html`, `website-terms.html`
- About the publication: `about.html`, `how-we-test.html`, `affiliate-disclosure.html`

The earlier web-studio portfolio, case studies, and concept sites (garage, builder, marine, restaurant, shop, stays) have been removed.

## Notes

- Do not add analytics, advertising cookies, or embedded widgets without updating `cookies.html` and `privacy.html` first.
- Systeme.io affiliate links in the articles use the existing `sa` parameter. Leave those URLs intact.
